# HTML Doc

**HTML 파일 하나로 끝나는 문서 편집기.** 문서를 열면 브라우저에서 바로 글자와 서식을 고치고, 같은 파일에 저장합니다. 서버도, 계정도, 설치도 필요 없습니다.

[English](README.en.md) · [AI용 지침](SKILL.md) · [한국어 상세 가이드](references/guide.ko.md) · [최신 배포본 받기](https://github.com/tonywjs/html-doc/releases/latest)

![데스크톱에서 연 예시 문서](docs/media/doc-desktop.png)

현재 버전은 **1.7.0**입니다. 편집기와 변환 도구의 UI는 한국어이며, 문서 본문은 원하는 언어로 작성할 수 있습니다.

## 1분 만에 써보기

1. [demo.html](https://github.com/tonywjs/html-doc/releases/latest/download/demo.html)을 내려받습니다.
2. 브라우저로 엽니다. 더블클릭하면 됩니다.
3. 오른쪽 위 **✎ 편집**을 누르고 아무 문장이나 고쳐 봅니다.
4. **저장**을 누르면 대상 파일을 한 번 고릅니다. 그다음부터는 같은 파일에 덮어씁니다.

이미 만들어 둔 HTML이 있다면 [add-editor.html](https://github.com/tonywjs/html-doc/releases/latest/download/add-editor.html)을 내려받아 열고, 그 파일을 선택하면 편집 가능한 사본이 만들어집니다.

## 기능

### 메모: 근거와 의견을 문서 안에 남기기

본문을 선택하고 메모를 쓰면 그 자리에 붙습니다. 답글을 달고, 해결로 표시하고, 삭제할 수 있습니다. 선택 없이 쓰면 문서 전체 메모가 됩니다.

![메모 남기기, 답글, 해결](docs/media/notes.gif)

메모는 **파일 안에** 저장되므로 파일만 주고받으면 그대로 따라갑니다. 배포용 HTML에는 들어가지 않습니다.

### 변경 사항: 돌려받은 문서에서 바뀐 곳 보기

저장본이나 다른 HTML 파일과 비교해 바뀐 부분을 본문 위에 그대로 표시합니다. 초록은 추가, 빨강은 삭제, 파랑은 수정(단어 단위), 보라는 서식 변경입니다.

![변경 사항 비교와 원래대로](docs/media/changes.gif)

비교 기준은 세 가지 중에 고릅니다. 마지막 저장 이후, 파일 안 히스토리의 저장본, 또는 다른 HTML 파일입니다. 기본값은 **나 아닌 사람이 저장한 가장 최근 버전**이라, 돌려받은 문서를 열면 상대가 고친 것만 보입니다. 마음에 안 드는 변경은 **원래대로**로 되돌립니다.

### 블록 삭제: 덩어리째 지우기

문단, 카드, 표의 행처럼 덩어리를 통째로 지웁니다. **블록 선택**으로 대상을 잡고(다시 누르면 상위 블록으로 넓어집니다), **블록 삭제**로 지운 뒤, 토스트의 **되돌리기**나 `Ctrl/Cmd+Z`로 복원합니다.

![블록 선택, 삭제, 되돌리기](docs/media/block-delete.gif)

표에서는 칸이 아니라 **행 단위**로 지웁니다. 칸 하나만 빼면 열이 어긋나기 때문입니다. 브라우저 기본 삭제를 쓰지 않는 이유도 같습니다. 기본 삭제는 지운 블록을 이웃과 합치면서 살아남은 블록의 스타일을 잃습니다.

### 전체 흐름

돌려받은 문서를 열고, 변경 사항을 보고, 되돌리고, 메모로 주고받는 과정을 이어서 보려면 [전체 흐름 영상(28초)](docs/media/walkthrough.mp4)을 참고하세요.

## 사용법

### 편집과 저장

| 하고 싶은 것 | 방법 |
|---|---|
| 편집 켜고 끄기 | 오른쪽 위 **✎ 편집** 또는 `Cmd/Ctrl+E` |
| 글자·서식 바꾸기 | 편집 툴바의 단락 스타일, 글씨체, 크기, 굵게/기울임/밑줄/취소선, 글자색, 배경색, 정렬, 목록, 표 |
| 현재 위치의 서식 확인 | **현재 서식** 패널 |
| 저장 | **저장** 또는 `Cmd/Ctrl+S` |
| 다른 파일로 저장 | 더보기 → **다른 이름으로** |

저장은 지원 브라우저(Chrome, Edge 등)에서 **처음 한 번만** 대상 파일을 고릅니다. 그 뒤로는 같은 파일에 덮어쓰며, 브라우저가 쓰기 권한을 다시 물을 수 있습니다. File System Access를 지원하지 않는 브라우저(Safari, Firefox)에서는 다운로드로 동작합니다.

### 자동저장과 복구

입력하면 브라우저 안에 백업이 남습니다. 파일 저장과는 별개입니다. 저장하지 않고 닫았다가 다시 열면 복구 안내가 뜹니다.

- **복구**: 백업 내용을 본문에 되살립니다. 파일에도 반영하려면 저장하세요.
- **무시**: 이번만 닫습니다. 다음에 열면 다시 안내합니다.
- **무시하고 현재 버전으로 백업 확정**: 이전 백업을 지금 본문으로 바꿉니다.

첫 저장 때 문서에 고유 ID가 생겨 백업이 문서별로 구분됩니다. 파일 이름이 같아도 다른 문서의 백업이 섞이지 않고, 지금 연 파일과 다른 저장본에서 만든 백업이면 복구 전에 알려 줍니다.

### 이름과 저장 기록

첫 메모나 첫 저장 때 이름을 한 번 묻고 브라우저에 기억합니다. 메모 패널에서 언제든 바꿀 수 있습니다. 저장할 때마다 누가 언제 저장했는지 기록되어, 히스토리와 비교 기준 목록에 이름이 함께 보입니다. 이름은 문서가 아니라 사용하는 브라우저에 저장됩니다.

### 배포용 HTML 저장

더보기 → **배포용 HTML 저장**을 누르면 편집기, 히스토리, 메모를 뺀 사본을 내려받습니다. 본문과 디자인, 문서 자체의 스크립트는 그대로 남습니다. 원본 파일은 바뀌지 않습니다.

일반 저장 파일에는 이전 본문이 히스토리로 남을 수 있습니다. 외부에 공유할 파일이라면 배포용 저장을 쓰세요.

### 기존 HTML에 편집기 추가

`tools/add-editor.html`을 열고 HTML 파일을 고르면 `원래파일명-편집가능.html` 사본을 내려받습니다. 원본은 덮어쓰지 않습니다. 편집 중인 문서에서도 더보기 → **HTML에 편집기 추가**로 같은 일을 할 수 있습니다.

### 모바일

너비 900px 이하에서는 상단에 편집, 저장, 메모, 더보기 버튼이 한 줄로 놓입니다. 나머지 기능은 더보기 안에 있고, 편집 툴바는 좌우로 넘겨서 씁니다.

## AI 스킬로 설치

Claude Code나 Codex에서 문서를 만들게 하려면 `SKILL.md`만 복사하지 말고 **폴더 전체**를 설치합니다.

| 환경 | 설치 위치 | 호출 예시 |
|---|---|---|
| Claude Code | `~/.claude/skills/html-doc/` | `/html-doc 편집 가능한 보고서를 만들어줘` |
| Codex | `~/.agents/skills/html-doc/` | `$html-doc 편집 가능한 보고서를 만들어줘` |

프로젝트 안에서만 쓸 때는 프로젝트의 `.claude/skills/` 또는 `.agents/skills/`에 넣습니다. 최종 경로가 `html-doc/SKILL.md`인지 확인하세요.

## 개발과 검증

```sh
python3 assets/build-template.py      # 엔진을 골격·예시·변환 도구에 다시 인라인
python3 scripts/check-release.py      # 패키지 검사
python3 scripts/package-release.py    # 배포용 ZIP과 SHA-256 생성
node --test tests/unit/*.test.js      # 비교 엔진 단위 검증
```

Python 3.9 이상은 재빌드와 검증에만 필요합니다. 만들어진 문서를 쓰는 사람에게는 필요하지 않습니다. 브라우저 회귀 검증은 [검증 안내](tests/README.md)를 참고하세요.

## 알아둘 점

- 편집 기능은 `contenteditable`과 `execCommand` 위에 있습니다. 브라우저마다 서식 동작이 조금씩 다를 수 있습니다.
- 자동 변환은 본문을 감싸는 컨테이너를 추가할 수 있어, `body > ...` 선택자나 부모 구조에 의존하는 스크립트는 변환 후 확인이 필요합니다.
- 상대 경로 이미지나 CSS를 쓰는 문서는 결과 파일을 원본과 같은 폴더에 두세요.
- 배포본에도 문서 자체 스크립트와 외부 리소스 참조는 남습니다. 스크립트를 정화하거나 서버에 게시하는 기능이 아닙니다.
